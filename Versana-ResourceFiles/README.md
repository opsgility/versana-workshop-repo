# Versana-ResourceFiles — Demo Files for Live Walkthroughs

This folder contains a small set of fictional sample files the facilitator uploads to OneDrive before a session. They give the demo prompts something concrete to reference. None of these files contain real Versana product, customer, partner, or employee information — they are clearly fictional B2B SaaS / fintech examples.

## Files

| File | Format | Used in |
|---|---|---|
| `Versana_Sample_PRD.md` → `Versana_Sample_PRD.docx` | Word | Outlook (UC-04 fallback), Teams meeting prep (UC-05), Word memo (UC-08), PowerPoint outline (UC-10) |
| `Versana_Sample_Ops_Runbook.md` → `Versana_Sample_Ops_Runbook.docx` | Word | Word memo (UC-08), Teams summary references (UC-06) |
| `Versana_Sample_Meeting_Transcript.md` → `Versana_Sample_Meeting_Transcript.docx` | Word | Teams summary (UC-06) — used as a backup when no live recording is available |
| `Versana_Sample_Vendor_List_README.md` → `Versana_Sample_Vendor_List.xlsx` | Excel | Excel vendor comparison (UC-11) |
| `Versana_Sample_Sprint_Summary.md` → `Versana_Sample_Sprint_Summary.docx` | Word | Word release notes (UC-09) |

## Pre-session setup

1. Convert each `.md` spec to its target binary format (`.docx` or `.xlsx`).
2. Upload the binary files to a OneDrive folder that the facilitator's account can reach.
3. Open each file once in the relevant Office app for the web (Word, Excel) — this adds them to your Most Recently Used list so Copilot can find them when you reference them in prompts.

> **All content in these files is fictional.** Don't use them as templates for real product specs, runbooks, or vendor lists without replacing the content with validated, internally-sourced material.
