# Agenda — Versana Microsoft 365 Copilot Workshop

**Format:** 1 hour follow-along overview + 1 hour live Q&A and applied use cases  
**Total length:** 2 hours (hard cap)  
**Audience:** Mixed — operations, product, exec assistants, customer success, finance, legal, broader business. Developers (already on GitHub Copilot) welcome; M365 Copilot is the focus.  
**Delivery:** Onsite preferred; virtual or hybrid available

---

## Hour 1 — Overview & Follow-Along (60 min)

Live walkthrough on the facilitator's screen. Attendees follow along on their own machines and run prompts in real time.

| Time | Block | What happens |
|---|---|---|
| 0:00 – 0:05 | **Welcome & ground rules** | Format expectations, AI/data-handling reminder, "follow along on your own machine" framing |
| 0:05 – 0:15 | **The prompting framework** | Walk through Goal → Context → Sources → Expectations with one live Outlook example |
| 0:15 – 0:25 | **Demo 1 — Outlook** | Draft an email, iterate twice, use Change Tone. Includes a 90-second silent practice block where everyone writes a prompt for a real email they need to send today. |
| 0:25 – 0:35 | **Demo 2 — Teams** | Meeting prep prompt + meeting summary prompt. Role callouts for exec assistants, product, and ops. 60-second silent practice block. |
| 0:35 – 0:43 | **Demo 3 — Word** | First-draft a one-page internal memo, then revise live using the Rewrite action |
| 0:43 – 0:49 | **Demo 4 — PowerPoint** | Outline-first pattern: write the outline in Word, then generate the deck in PowerPoint |
| 0:49 – 0:55 | **Light touch — Excel + SharePoint** | One Excel demo (vendor / external service comparison) + the "SharePoint is where Copilot finds your files" framing |
| 0:55 – 1:00 | **Three habits & hour 2 setup** | Recap the durable habits; invite questions for hour 2; drop the take-home prompt sheet into the Teams chat |

**Optional 5-minute break before hour 2.**

---

## Hour 2 — Live Q&A and Applied Use Cases (60 min)

Audience-driven. Attendees ask role-specific questions; the facilitator demos answers in real time, drawing from a prepared use-case library when helpful.

The pattern repeats throughout the hour:
1. Attendee asks a question
2. Facilitator translates it into the framework (Goal → Context → Sources → Expectations) out loud
3. Facilitator runs the prompt live and iterates visibly
4. Attendees try the same prompt on their own work for 60–90 seconds

**Use-case library (~12 walkthroughs the facilitator can pull from in real time):**

| App | Use cases ready to demo |
|---|---|
| Outlook | Reply to a long thread, status update, decline a meeting respectfully, the email you've been putting off |
| Teams | Meeting prep in 30 minutes, meeting summary for a channel, catch up on a channel you've ignored |
| Word | Internal decision memo, release notes from a sprint summary |
| PowerPoint | Roadmap deck from a one-page outline |
| Excel | Vendor / external service comparison |
| SharePoint | "Where does Copilot find the files?" framing |

**Last 5 minutes:** Each attendee names one prompt they'll use this week. Confirm prompt sheet is posted. Set any follow-up commitments.

---

## Pre-session prep (1 week out)

- Confirm Microsoft 365 Copilot license tier for all attendees
- Confirm Versana's internal AI / data-handling policy and surface it in hour 1
- Upload the demo resource files to OneDrive; open each one once in its app for the web
- Send a calendar invite that asks attendees to confirm Copilot is enabled in Outlook, Teams, and OneDrive before the session

## Post-session

- Post the take-home prompt sheet in the relevant Teams channel
- Send a 5-line follow-up email: what we covered, the prompt sheet, link to the use-case library, calendar holds for any follow-up sessions
- Capture questions that didn't get answered live — they become the next session's content

---

## Hybrid model (if running Part 1 virtual + Part 2 onsite)

If the audience is large (>30) or mostly new to Copilot, the workshop can be split:

| Session | Length | Focus |
|---|---|---|
| **Part 1 — Virtual overview** | ~55 min | Compressed hour 1: framework + 3 demos + homework assignment |
| **Between sessions** | 2–4 weeks | Attendees use Copilot in real work; facilitator captures questions in Teams |
| **Part 2 — Onsite deeper dive** | 2 hours | Recap → patterns from Part 1 → 45-min hands-on rotations by role → group share-back → live Q&A → close |
